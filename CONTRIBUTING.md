# Contributing to Piux 💚

Thanks for your interest in contributing to **Piux**!

Piux is a small experimental operating system built from scratch with the goal of learning, experimenting, and having fun with low-level development.
Contributions are welcome, whether you're fixing a bug, improving something, adding a new feature, writing an application, or improving the documentation.

## Before contributing

If you want to work on Piux, make sure you understand what your changes are supposed to do and test them before opening a Pull Request.
Please try to keep your changes focused and avoid including unrelated modifications.
If you're planning a large change, feel free to discuss it first on the [Fluxer Piux server](https://fluxer.gg/lKT2g2bd).

## Pull Requests

Piux uses Pull Requests to review and merge contributions.

Before submitting one:

* Make sure everything builds correctly.
* Test the changes you made.
* Check that existing features still work.
* Explain what you changed and why.

Every Pull Request will be reviewed before being merged.
If something needs to be changed, don't worry! Feedback is part of the development process. You can update your Pull Request and have it reviewed again.

## Code

Try to keep the code simple, readable, and consistent with the rest of the project.
Piux is still evolving, so some parts of the codebase may change over time. When possible, follow the existing structure instead of making unnecessary large changes.

## Applications and Packages

Piux supports independent applications, including ELF programs, and is also developing **Pix**, its package manager.
Contributions to applications and packages are welcome too. Please make sure they work correctly with the current version of Piux and follow the project's conventions.

## Bug Reports

If you find a bug, feel free to open an issue (or fix yourself with a Pull Requests).
Please provide enough information for someone else to understand what happened and reproduce the problem.

## Be Respectful

Piux is an open-source project and everyone is welcome to contribute.
Please be respectful towards other contributors, **accept constructive feedback**, and keep **discussions friendly**.

You don't need to be an expert to contribute. Piux is a learning project, so experimenting and learning along the way is encouraged.
